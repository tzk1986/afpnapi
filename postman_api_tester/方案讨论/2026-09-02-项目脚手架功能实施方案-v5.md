## 五、检查点体系（防偏离）

### 5.1 三级检查点
- **步级**：上表"验证"列命令，即写即跑，不过不 commit；
- **阶段级（G1~G4）**：全量 pytest + mypy + **白名单 diff** + 零回归抽查；
- **收口级（S4.4）**：v3 5.2 接口总表逐行勾验（18/18）+ v3 六节验收表逐条过 + 安全用例（XSS/穿越/开关/secret 脱敏 R15）。

### 5.2 防偏离机制
1. **方案条目 ↔ 步骤映射**：每步 commit message 带 S 编号；收口贴映射表；无对应步骤的"顺手改动"一律回退（方案/实施分离）。
2. **共享文件白名单**（比 v4 更严，含 M2 修正）：`git diff --name-only master...HEAD` 允许集 = {config.py, report_server.py, page_routes.py, index.html, base_handler.py(仅注释), pyproject.toml, .gitignore, __init__.py(S4.3), 6 文档}；出现集外文件即停。
3. **grep 断言（G1 起每阶段跑一次）**：
   ```bash
   git grep -n "=== 'success'\|== \"success\"" -- 'templates/project_*' && echo FAIL   # 响应契约
   git grep -n "register_project_routes\|extends \"base.html\"\|bootstrap\|jquery" -- 'templates/project_*' && echo FAIL
   git grep -n "get_json()" -- 'postman_api_tester/handlers/project_routes.py' && echo FAIL  # 必须 silent=True
   git grep -n "shutil.rmtree" -- 'postman_api_tester' | grep -v test | wc -l  # 仅允许 store 受控 2 处（delete+回滚）
   git grep -n "rmtree\|PROJECTS_DIR /" -- 'postman_api_tester/services/project_store.py'  # 人工核对每处前必有 is_relative_to
   ```
4. **红线端点逐字节**：`/health`、`/api/log-metrics`、`/api/reports`、`/api/report-meta/*`、`/api/run-postman-status/*` 的 handler 文件在 diff 白名单外且 diff 为空。
