## 一、背景与目标

### 1.1 问题现状

| 问题 | 描述 | 影响 |
|------|------|------|
| **新人上手难** | 接手自动化项目需理解目录结构、命名规范、变量配置、执行方式等 | 1-2 周才能独立工作 |
| **规范难落地** | 20 页规范文档写了没人看，命名还是各自为政 | 项目结构混乱，维护困难 |
| **知识难传承** | 踩坑经验在群聊/脑子里，老人离职知识丢失 | 重复踩坑，效率低下 |
| **项目难复制** | 只有架构师能创建规范的项目 | 团队无法规模化扩展 |
| **追溯难管理** | Excel 追溯表散落各处，与 Collection 脱节 | 无法自动统计自动化率 |

### 1.2 目标定义

通过**报告中心 UI 集成项目脚手架**，实现：

1. **一键创建** - 新人在 5 分钟内创建标准化项目
2. **规范强制** - 模板自带规范，从源头避免错误
3. **知识沉淀** - 每个项目自动沉淀文档和经验
4. **规模扩展** - 任何人都能创建项目，不依赖专人
5. **自动追溯** - 追溯表与 Collection 联动，实时统计

### 1.3 预期收益

| 维度 | 当前 | 目标 | 提升 |
|------|------|------|------|
| 新人上手时间 | 1-2 周 | 1-2 天 | ⬇️ **80%** |
| 项目初始化耗时 | 2-4 小时 | 5 分钟 | ⬇️ **95%** |
| 规范遵循率 | 60-70% | 95%+ | ⬆️ **30%+** |
| 知识传承成本 | 靠人口传 | 模板自带 | ⬇️ **70%** |

## 二、核心概念设计

### 2.1 概念模型

```
┌─────────────────────────────────────────────────────────────┐
│                        项目 (Project)                        │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 元数据：名称、负责人、系统类型、JIRA 编号、状态等       │  │
│  │ 配置：环境、鉴权、执行策略、通知配置                   │  │
│  └───────────────────────────────────────────────────────┘  │
│                                                              │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐      │
│  │ Collection 1 │  │ Collection 2 │  │ Collection N │      │
│  │ (模块/JIRA)  │  │ (模块/JIRA)  │  │ (模块/JIRA)  │      │
│  └──────────────┘  └──────────────┘  └──────────────┘      │
│                                                              │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 追溯表 (自动维护 Collection <-> 用例 <-> 状态)         │  │
│  └───────────────────────────────────────────────────────┘  │
│                                                              │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 文档：README、踩坑记录、操作手册                       │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 与现有概念的关系

| 概念 | 层级 | 说明 | 关系 |
|------|------|------|------|
| **Project（新增）** | 项目层 | 业务维度的完整自动化项目 | 1 个项目包含多个 Collection |
| **Collection（已有）** | 集合层 | 一组相关的接口请求 | 属于某个项目 |
| **Request（已有）** | 请求层 | 单个接口请求 | 属于某个 Collection |
| **Environment（已有）** | 环境层 | 变量配置集合 | 项目引用全局环境 |

### 5.3 代码实现示例

#### 5.3.1 路由层（project_routes.py）

```python
"""项目脚手架路由处理函数。"""

import logging
from pathlib import Path
from flask import request, render_template
from flask.typing import ResponseReturnValue

from postman_api_tester.handlers.base_handler import BaseHandler, json_error
from postman_api_tester.services.project_service import ProjectService
from postman_api_tester.services.project_template_service import ProjectTemplateService

logger = logging.getLogger(__name__)

PROJECT_ROOT = Path(__file__).resolve().parent.parent
PROJECTS_DIR = (PROJECT_ROOT / "projects").resolve()
TEMPLATES_DIR = (PROJECT_ROOT / "project_templates").resolve()


def project_index() -> ResponseReturnValue:
    """项目列表页面。"""
    return render_template("project_index.html")


def project_create_page() -> ResponseReturnValue:
    """项目创建页面。"""
    templates = ProjectTemplateService.list_templates()
    return render_template("project_create.html", templates=templates)


def project_detail_page(project_id: str) -> ResponseReturnValue:
    """项目详情页面。"""
    project = ProjectService.get_project(project_id)
    if not project:
        return json_error("项目不存在", 404, "PRJ_001")
    return render_template("project_detail.html", project=project)


def api_create_project() -> ResponseReturnValue:
    """创建项目 API。"""
    data = request.get_json()
    if not data:
        return json_error("请求体不能为空", 400, "PRJ_002")
    
    # 参数校验
    name = data.get("name", "").strip()
    if not name:
        return json_error("项目名称不能为空", 400, "PRJ_003")
    
    template_id = data.get("template_id", "tpl_api_basic")
    
    try:
        project = ProjectService.create_project(
            name=name,
            description=data.get("description", ""),
            template_id=template_id,
            metadata=data.get("metadata", {}),
            config=data.get("config", {})
        )
        return BaseHandler.json_response(
            {"project_id": project["id"], **project},
            201
        )
    except ValueError as e:
        return json_error(str(e), 400, "PRJ_004")
    except Exception as e:
        logger.exception("项目创建失败")
        return json_error(f"项目创建失败：{e}", 500, "PRJ_005")


def api_list_projects() -> ResponseReturnValue:
    """项目列表 API。"""
    page = request.args.get("page", 1, type=int)
    page_size = request.args.get("page_size", 20, type=int)
    system = request.args.get("system")
    status = request.args.get("status")
    
    result = ProjectService.list_projects(
        page=page,
        page_size=page_size,
        system=system,
        status=status
    )
    return BaseHandler.json_response(result)


def api_get_project(project_id: str) -> ResponseReturnValue:
    """获取项目详情 API。"""
    project = ProjectService.get_project(project_id)
    if not project:
        return json_error("项目不存在", 404, "PRJ_006")
    return BaseHandler.json_response(project)


def api_execute_project(project_id: str) -> ResponseReturnValue:
    """执行项目 API。"""
    data = request.get_json() or {}
    
    try:
        job = ProjectService.execute_project(
            project_id=project_id,
            collections=data.get("collections"),
            environment=data.get("environment"),
            concurrent=data.get("concurrent", False)
        )
        return BaseHandler.json_response(job)
    except ValueError as e:
        return json_error(str(e), 400, "PRJ_007")
    except Exception as e:
        logger.exception("项目执行失败")
        return json_error(f"项目执行失败：{e}", 500, "PRJ_008")


def register_project_routes(app) -> None:
    """注册项目相关路由。"""
    # 页面路由
    app.add_url_rule("/projects", view_func=project_index, endpoint="project_index")
    app.add_url_rule("/projects/create", view_func=project_create_page, endpoint="project_create")
    app.add_url_rule("/projects/<project_id>", view_func=project_detail_page, endpoint="project_detail")
    
    # API 路由
    app.add_url_rule("/api/projects", view_func=api_list_projects, methods=["GET"])
    app.add_url_rule("/api/projects", view_func=api_create_project, methods=["POST"])
    app.add_url_rule("/api/projects/<project_id>", view_func=api_get_project, methods=["GET"])
    app.add_url_rule("/api/projects/<project_id>/execute", view_func=api_execute_project, methods=["POST"])
```

#### 5.3.3 存储层（project_store.py）

```python
"""项目存储层。"""

import json
import logging
from pathlib import Path
from typing import Any, Dict, List, Optional

logger = logging.getLogger(__name__)

PROJECTS_DIR = Path(__file__).resolve().parent.parent.parent / "projects"


class ProjectStore:
    """项目数据存储。"""
    
    @staticmethod
    def save_project(project_id: str, project_data: Dict[str, Any]) -> None:
        """保存项目。"""
        project_dir = PROJECTS_DIR / project_id
        project_file = project_dir / "project.json"
        
        project_file.write_text(
            json.dumps(project_data, ensure_ascii=False, indent=2),
            encoding="utf-8"
        )
    
    @staticmethod
    def get_project(project_id: str) -> Optional[Dict[str, Any]]:
        """获取项目。"""
        project_file = PROJECTS_DIR / project_id / "project.json"
        
        if not project_file.exists():
            return None
        
        try:
            return json.loads(project_file.read_text(encoding="utf-8"))
        except Exception as e:
            logger.error(f"读取项目失败：{project_id}, {e}")
            return None
    
    @staticmethod
    def list_all_projects() -> List[Dict[str, Any]]:
        """列出所有项目。"""
        if not PROJECTS_DIR.exists():
            return []
        
        projects = []
        for project_dir in PROJECTS_DIR.iterdir():
            if project_dir.is_dir():
                project = ProjectStore.get_project(project_dir.name)
                if project:
                    projects.append(project)
        
        # 按创建时间倒序
        projects.sort(
            key=lambda p: p.get("metadata", {}).get("created_at", ""),
            reverse=True
        )
        
        return projects
    
    @staticmethod
    def delete_project(project_id: str) -> bool:
        """删除项目。"""
        import shutil
        
        project_dir = PROJECTS_DIR / project_id
        if not project_dir.exists():
            return False
        
        try:
            shutil.rmtree(project_dir)
            logger.info(f"项目删除成功：{project_id}")
            return True
        except Exception as e:
            logger.error(f"删除项目失败：{project_id}, {e}")
            return False
```

## 八、风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| **与现有逻辑冲突** | 破坏现有功能 | 新增模块，不修改现有代码 |
| **文件系统性能** | 项目多了性能下降 | 限制单页 20 个，分页加载 |
| **模板不通用** | 无法满足所有场景 | 提供自定义模板功能 |
| **追溯表不准确** | 统计数据错误 | 定期同步校验 |
| **执行失败无回滚** | 产生脏数据 | 执行前备份 |
