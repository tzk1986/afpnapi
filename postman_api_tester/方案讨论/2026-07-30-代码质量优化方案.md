### 2.2 请求重试机制

**问题描述**：
当前执行器在请求失败时直接返回错误，未实现自动重试，导致网络抖动时测试失败率偏高。

**实施方案**：

#### 2.2.1 配置项
在 `config.py` 添加：
```python
# 请求重试配置
ENABLE_REQUEST_RETRY = _env_bool("ENABLE_REQUEST_RETRY", False)
REQUEST_RETRY_TOTAL = _env_int("REQUEST_RETRY_TOTAL", 3)
REQUEST_RETRY_BACKOFF_FACTOR = _env_float("REQUEST_RETRY_BACKOFF_FACTOR", 1.0)
REQUEST_RETRY_STATUS_FORCELIST = _env_tuple("REQUEST_RETRY_STATUS_FORCELIST", (429, 500, 502, 503, 504))
```

#### 2.2.2 实现位置
在 `session.py::create_shared_session()` 中配置重试策略：
```python
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

def create_shared_session() -> SessionLike:
    import requests as _requests_mod
    
    if config.ENABLE_REQUEST_RETRY:
        retry_strategy = Retry(
            total=config.REQUEST_RETRY_TOTAL,
            backoff_factor=config.REQUEST_RETRY_BACKOFF_FACTOR,
            status_forcelist=config.REQUEST_RETRY_STATUS_FORCELIST,
            allowed_methods=["HEAD", "GET", "POST", "PUT", "DELETE", "PATCH"],
        )
        adapter = HTTPAdapter(max_retries=retry_strategy)
        session = _requests_mod.Session()
        session.mount("http://", adapter)
        session.mount("https://", adapter)
        return cast(SessionLike, session)
    
    return cast(SessionLike, _requests_mod.Session())
```

在 `tests/test_session.py` 添加：


#### 2.3.2 智能失效
在 `report_repository.py::list_reports()` 添加文件修改时间检查：
```python
def list_reports(self) -> List[ReportMeta]:
    cache_key = "reports_list"
    cached = self._cache.get(cache_key)
    
    if cached:
        cached_time, cached_data = cached
        # 检查是否有新报告生成
        latest_mtime = self._get_latest_mtime()
        if cached_time >= latest_mtime:
            return cached_data
    
    # 重新扫描
    reports = self._scan_reports()
    self._cache.set(cache_key, (time.time(), reports))
    return reports

def _get_latest_mtime(self) -> float:
    """获取报告目录的最新修改时间"""
    reports_dir = Path(config.REPORT_OUTPUT_DIR)
    if not reports_dir.exists():
        return 0
    
    latest = 0
    for meta_file in reports_dir.rglob("*_meta.json"):
        mtime = meta_file.stat().st_mtime
        if mtime > latest:
            latest = mtime
    return latest
```

### 3.2 UI 代理 SSRF 防护

**问题描述**：
`ui_proxy_service.py` 未验证目标 URL 是否为内网地址，存在 SSRF 风险。

**实施方案**：

#### 3.2.1 URL 安全检查函数
在 `utils/security.py` 添加：
```python
import ipaddress
from urllib.parse import urlparse

def is_safe_url(url: str) -> bool:
    """检查 URL 是否安全（非内网地址）"""
    try:
        parsed = urlparse(url)
        hostname = parsed.hostname
        
        if not hostname:
            return False
        
        # 禁止访问常见内网地址
        if hostname in ('127.0.0.1', 'localhost', '0.0.0.0', '[::1]'):
            return False
        
        # 禁止私有 IP 段
        try:
            ip = ipaddress.ip_address(hostname)
            if ip.is_private or ip.is_loopback or ip.is_link_local:
                return False
        except ValueError:
            pass  # 非 IP 地址（域名），允许
        
        return True
    except Exception:
        return False
```

#### 3.2.2 集成到代理服务
在 `ui_proxy_service.py::proxy_request()` 添加检查：
```python
def proxy_request(self, url: str, ...) -> Response:
    if not is_safe_url(url):
        raise ValidationError(f"禁止访问内网地址: {url}")
    
    # 继续原有逻辑
    ...
```

#### 3.2.3 测试覆盖
```python
def test_is_safe_url_public(self):
    """公网地址应允许"""
    assert is_safe_url("https://example.com") is True
    assert is_safe_url("https://api.github.com") is True

def test_is_safe_url_private(self):
```

### 3.3 pathlib 迁移

**问题描述**：
15 处使用 `open()` 而非 `pathlib.Path.open()`，40+ 处使用 `os.path` 而非 `pathlib`。

**实施方案**：

#### 3.3.1 高频路径优先
优先迁移以下模块：
- `core/report_engine.py`（报告生成）
- `utils/file_utils.py`（文件写入）
- `services/report_export_service.py`（导出）

#### 3.3.2 迁移示例
```python
# 当前
import os
from pathlib import Path

def save_report(report_path: str, data: dict):
    os.makedirs(os.path.dirname(report_path), exist_ok=True)
    with open(report_path, 'w', encoding='utf-8') as f:
        json.dump(data, f)

# 改进
from pathlib import Path

def save_report(report_path: str | Path, data: dict):
    path = Path(report_path)
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open('w', encoding='utf-8') as f:
        json.dump(data, f)
```

#### 3.3.3 逐步迁移
- 第一阶段：核心路径（report_engine、file_utils）
- 第二阶段：服务层（report_export、report_delete）
- 第三阶段：工具函数（url_utils、data_driver）

**影响范围**：
